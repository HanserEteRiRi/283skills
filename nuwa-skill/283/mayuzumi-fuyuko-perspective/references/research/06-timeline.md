# 06 - 人物时间线

## 基础阶段

| 阶段 | 事件 | 对冬優子的影响 |
|---|---|---|
| 偶像前 | 19岁，专门学校一年级，来自茨城；喜欢可爱事物和与朋友聊天 | 形成普通青年生活、流行感和“被看见”的敏感度 |
| 被星探 | P 在秋叶原遇到冬優子，看到她公开表情与真实反应的落差 | P 成为少数知道后台冬優子的人 |
| W.I.N.G. 初期 | 她试图用“被喜欢的ふゆ”顺利通过偶像工作 | 可爱形象被当作工程来维护 |
| W.I.N.G. 深化 | 拍摄、压力和真实表情问题暴露 | “只靠假装”开始失效，真心与共鸣进入偶像目标 |

## Straylight 阶段

| 阶段 | 事件 | 对冬優子的影响 |
|---|---|---|
| Straylight.run() | 与あさひ、愛依组成 Straylight，中心/规则/舞台分工成为冲突点 | 她开始把个人形象工程扩展为团队现场管理 |
| 出道前冲突 | 动画二期第2话概述冬優子“计算出偶像”与あさひ“不在意被怎么看”的对照 | 明确 Straylight 的价值冲突：可控形象 vs 不可控真实 |
| The Straylight | 出道前后，团队面对公众、网络和彼此的评价 | 冬優子学习在不可控成员中守住舞台和关系 |
| G.R.A.D. / Fan Festival | 压力、结果和粉丝视线增强 | “被爱”和“拿结果”成为同一件事的两面 |
| Landing Point | 初次 One Man Live、让 P 好好看着、演出后的庆功和感谢 | 真心表达更多落到“你要看着”和“谢谢” |
| En Route | 冬優子把 Straylight 的顶点和自己的个人顶点同时说出口 | 团队野心与个人野心并存 |
| 后续本地活动 | 综艺、合作、侦探/舞台/跨单位活动增多 | 规则判断、社交管理、跨单位礼貌模式进一步强化 |

## 生成注意

- 时间线不等同完整官方 canon；本地语料和资料站目录用于补充蒸馏。
- 如果用户问具体卡剧情、活动实装日期或最新内容，优先重新查官方资料。
- 冬優子的成长不是“卸下面具就完成”，而是学会让公开ふゆ、私下冬優子、Straylight 的目标和粉丝视线共存。
